# 板级硬件定制需求 — 8 扬声器 / 8 误差麦 / 闭环自适应 ANC

> **版本**: v1.0 (2026-08-20) | **最后修订**: 2026-09-02
> **用途**: 交给电路板定制厂商的整板需求规格。架构决策: 8 扬声器 + 8 误差麦 + 闭环（误差麦**标定期**在环自适应收敛成品滤波器，部署开环无误差麦）。
> **底层依据**: [窗户ANC可行性-因果限制_实测_方案.md §4.8](窗户ANC可行性-因果限制_实测_方案.md)
> **验收预算**: 本文档已并入原 `8x8_实时性验收预算表.md`（2026-09-02），预算母表见 §11。

> ⚠️ **状态声明**: 本规格面向**尚未开发的 8S8E 定制板**（远期规划）。与当前 PC 原型（**3 麦 2 扬 / SFANC 硬选 7 槽库 / fixed 开环部署**）是**两套不同状态**——代码架构 2026-08-22 起为 SFANC 硬选（CNN K=7 argmax 选 1/7 成品槽，非"CNN 直接权重连续组合"），下述规格中"闭环自适应"指**真机标定填库**那一环。

---

## 0. 系统概述

开窗主动降噪（ANC）控制器。1 支参考麦（窗外）拾取噪声，8 支误差麦（窗内）作为降噪目标点，8 个扬声器（窗洞周边布置）播放反噪声。标定时时域 MIMO FxLMS 逐样本自适应收敛成品滤波器（写库槽），部署时分类 CNN 慢环路（1Hz）**每秒从库中选 1/7 成品滤波器槽** → crossfade 切换，开环播放（无误差麦）。

**核心性能目标**:

| 指标 | 目标 |
|---|---|
| 有效降噪频段 | 20-500Hz（马路噪音主体） |
| 环路延迟 | **≤2ms**（硬约束） |
| 空间采样上限 | ~400-500Hz（8 扬声器周边 42cm 间距） |
| 预期 NR | 整窗能量平均 ~6-9dB / 误差麦点测 10-15dB |

**三条硬约束（任何环节不可妥协）**:
1. **低延迟**: 全链路 ≤2ms。通用 codec 的 1-2ms 转换延迟会直接吃光预算。
2. **逐样本处理**: DSP 按 16kHz 逐样本中断处理，**非块缓冲**。块缓冲（如 PC 的 128 样本）会把延迟抬高 2.7ms。
3. **确定性实时**: 裸机 / RTOS，**不可用 Linux+ALSA**（附加 5-10ms 延迟）。

## 1. 算力需求

主控 DSP 需持续吞吐 **≥6 GMAC/s**（含余量）。逐模块 @16kHz、L=1024、E×S=64 路径（**口径 B，2026-08-21 更细拆分**）:

| 模块 | MAC/样本 |
|---|---|
| anti = Wc⊗x_hist（S×L） | 8,192 |
| Fx = Ŝ⊗ref（xd 更新，E×S×SEC_LEN） | 65,536 |
| 功率 Σxd²（E×S×L） | 65,536 |
| 梯度更新（E×S×L） | 65,536 |
| leak + Fx 带通（S×L + E×S×256）+ err 带通（E×256） | ~26,624 |
| ref 带通（CNN 输入 + ANC） | 1,280 |
| 反馈抵消（S×FB_LEN） | 4,096 |
| 杂项（AGC/EMA/钳位/VS-LMS） | ~500 |
| **前馈小计** | **~237,300 → 3.80 GMAC/s** |
| 在线 Ŝ 辨识（sec_online_update，可关） | +139,264 → **+2.23 GMAC/s** |
| **总计（开Ŝ）** | **~6.0 GMAC/s** |
| CNN 推理 @1Hz（均值） | ~0.1 GMAC/s |

> 📐 **口径说明**: 本规格 v1.0（08-20）曾给出一版更粗的拆分 **前馈 3.48 / 开Ŝ 5.84 GMAC/s**（口径 A，不含部分带通/反馈/杂项）。两版差异属模块口径，**非代码能力差异**；上板前按 §11.1 以口径 B 复核验收即可，不需并列维护。

建议优化项（固件实现）:

| 优化 | 效果 | 备注 |
|---|---|---|
| 功率归一化改滑动和（O(1)/样本） | FxLMS → ~2.4 GMAC/s | **首选**，直接决定能否开在线 Ŝ |
| 关在线 Ŝ（`GFANC_SEC_MU=0`） | −2.23 GMAC/s | 依赖出厂 64 条 Ŝ 校准 |
| 滤波器长度 L 1024→512 | 算力再减半 | 频率分辨率 15.6→31Hz，对 20-500Hz 够用；库槽换 512tap 需重标定/重训 |

**推荐规格**: 主控需在 62.5µs（16kHz 单采样周期）内算完全部通道。选型见 §3。

## 2. 内存需求

静态分配，无动态内存。fp32 满载 ≈ **3.6MB**（CNN int8 后 ~2.3MB）:

| 用途 | 大小 |
|---|---|
| CNN 激活 + 权重 | 1.84MB |
| FxLMS（xd/Ŝ 各 256KB + wc 32KB） | 0.53MB |
| 库槽 wc_bank（现行 7 槽 × S×L，随 S/L 扩） | 0.06MB/槽 @1×8×1024 |
| 16k 音频缓冲（ref 64K + err 512K + anti 512K） | 1.06MB |
| CNN 输入双缓冲 + 反馈 FIR | 0.13MB |

板载内存 ≥64MB DDR 即可（RK3568 标配 1-2GB，余量充足）。

## 3. 主控选型

| 项 | 要求 / 推荐 |
|---|---|
| **推荐** | **RK3568**（4×A55 @2GHz），实测持续 6-8 GMAC/s |
| 备选 | i.MX 8M Plus（A55+RTOS）；研究级 B-1 反馈用 Zynq-7000 FPGA |
| 排除 | i.MX RT1170（M7，实测 ~1 GMAC/s，**不够** 8×8） |
| 指令集 | 需 NEON/SIMD（FxLMS 内循环双段线性访问已 SIMD 友好） |
| 核心分配 | 音频逐样本中断（实时）+ CNN 独立核/线程（1Hz，双缓冲，不得阻塞音频中断） |

CNN 推理是结构性"不影响降噪量"要求：必须独立于音频路径、异步执行。

## 4. ADC 要求（麦克风输入）

| 项 | 要求 |
|---|---|
| 通道数 | **9ch**（1 参考麦 + 8 误差麦） |
| 采样率 | 48kHz（ANC 控制率 16kHz，3:1 抽取） |
| 位深 | **24-bit**（≥100dB SNR；16-bit 在 -40dBFS 工作点不够） |
| 转换延迟 | **≤0.5ms**（低延迟模式；ANC 级 codec） |
| 接口 | TDM 或 I2S，与 DAC 共享 MCLK/BCLK/LRCK |
| 参考麦 | **单独模拟输入通道**（窗外长线 + 防水罩，耐候） |
| 误差麦 | 可数字 MEMS（TDM 直连，省模拟前端） |
| 底噪 | 静音输入时 ≤ -90dBFS |

**推荐 codec**: 3× TLV320ADC6140（4ch/片 → 12ch，覆盖 9ch，余 3ch 备用）。
**麦克风选型**（替换 ECM8000）: 高灵敏度（≥-45dB）驻极体/MEMS，100-800Hz 平坦 ±3dB，参考麦必须防水耐候。

## 5. DAC 要求（扬声器输出）

| 项 | 要求 |
|---|---|
| 通道数 | **8ch** |
| 采样率 | 48kHz |
| 位深 | 24-bit（≥110dB SNR） |
| 转换延迟 | **≤0.5ms** |
| 接口 | I2S / TDM |
| 输出 | 模拟 → 功放（TPA3116D2，8ch）→ 扬声器 |
| 输出限幅 | 需防 NaN/Inf 防护（代码内已实现 ±1.0） |

**推荐 codec**: CS4382（8ch）。

## 6. 延迟预算（全链路 ≤2ms）

| 级 | 通用 codec | ANC 级低延迟 codec |
|---|---|---|
| ADC 转换 | 0.5-1ms | 0.2-0.5ms |
| DSP 处理（逐样本，全通道） | ~0.1ms | ~0.1ms |
| DAC 转换 | 0.5-1ms | 0.2-0.5ms |
| 环路滤波（功放/最小相位） | 0.2-0.5ms | 0.2-0.5ms |
| **合计** | **1.3-2.6ms ⚠️ 紧/超** | **0.7-1.6ms ✅** |

> ⚠️ 通用 codec 直接吃光预算，**必须指定 ANC 级低延迟 codec**（如 ADAU1787 或高速 I2S 转换器）。

## 7. 软件 / 固件要求

1. 裸机或 RTOS（FreeRTOS）；**禁用 Linux+ALSA**（附加 5-10ms，不可用）。
2. **逐样本中断**（16kHz），每中断内算完全部 8×8 路径（≤62.5µs）。
3. 音频 I/O 48kHz ↔ 控制率 16kHz，3:1 抽取/内插，跨中断相位连续。
4. 静态内存分配，无 `malloc`。
5. 提供 SPI/I2C 控制 codec（寄存器配置）、GPIO、UART 调试口、状态 LED。
6. 电源: 5V 主供 + 模拟/数字分离 + 低噪声 LDO（ADC SNR 敏感）。

## 9. 验收标准（给厂家的交付验证）

1. **环路延迟**: 扫频/脉冲法测 ADC→DSP→DAC 往返，**≤1ms**（留 1ms 给算法）。
2. **通道对齐**: 全部 9 入 8 出通道相位对齐，通道间延迟差 **<1 样本**（48kHz）。
3. **时钟**: MCLK/BCLK/LRCK 同步，抖动可测、无漂移。
4. **底噪**: 静音输入 ADC 底噪 ≤ -90dBFS。
5. **算力**: 板载实测跑满 8×8 FxLMS（L=1024）+ 在线 Ŝ + CNN @1Hz，单采样周期 <62.5µs，无 xrun。
6. **逐样本**: 确认固件为逐样本处理架构，无块缓冲。

## 11. 实时性验收预算（并入自原 8x8_实时性验收预算表，2026-08-21）

> **用途**: 上板前用静态预算定"必须达到的线"，上板后逐项实测比对。独立分析: 数字从 [src/fxnlms_mimo.c](../src/fxnlms_mimo.c)、[main_realtime.c](../main_realtime.c) 逐模块数出。

**一句话结论**: 8×8 实时性成立的前提 = **NEON + L≤512 + 关在线Ŝ（或 RK3588）+ 低延迟 codec（ADC+DAC <100µs）**，四条件缺一不可。RK3568 满足前三个后算力余量 2-3 倍；preview 余量 ~1.8ms；1m 参考距离的因果性够，相干性需实测。

### 11.1 算力验收线

- ✅ **达标**: 上板实测 8×8+L1024 单 tick < **62.5µs**（预算 100%），NEON 编译
- 🎯 **理想**: tick < **31µs**（预算 50%，留系统/CNN 余量）
- ⚠️ **降配可救**: 超预算 → L512 / 关在线Ŝ / 关反馈抵消，每项对半砍

RK3568（4×A55）对照: 标量 FP32 → 3.3 核不够 ❌；NEON 单核理论 14.4 GMAC/s → 26%（前馈）/42%（开Ŝ）；NEON 实际 50-70% 效率 → **38-54% ✅ / 60-86% ⚠️**；NEON + L512 → 19-43% ✅。

### 11.2 带宽预算（真实瓶颈，非 DRAM 容量问题）

- **工作集 544KB**（xd 256KB + Ŝ 256KB + Wc 32KB）恰好**超过 RK3568 全部 512KB L3** → 必有部分驻留 DRAM
- 开Ŝ 每样本访问 ~1.6MB/样本；L3 命中率 50-80% → DRAM 流量 **~7.7GB/s** ≈ RK3568 6.4GB/s 上限 ⚠️
- **L=512 或关在线Ŝ** → 工作集减半 → ~3.8GB/s ✅ 余量充足
- 换 RK3588（3MB L3 + A76 私有 L2）→ 此项直接解锁
- ✅ 达标: 持续实测吞吐 ≥ 6 GMAC/s，无 xrun/爆音

### 11.3 Preview / 因果预算（1m 参考麦）

`preview = 参考→误差声学延迟 − (codec ADC/DAC + DSP 处理 + 扬声器→误差声学延迟)`

| 分量 | 低延迟 codec | 通用 codec |
|---|---|---|
| 参考→误差（1m，声速 343m/s） | **+2.92ms** | +2.92ms |
| codec ADC+DAC | −40~100µs | −1.0~3.5ms |
| DSP（逐样本，算力够则≈0） | ~0 | ~0 |
| 扬声器→误差（0.2-0.5m） | −0.6~1.5ms | −0.6~1.5ms |
| **净 preview** | **+1.3~2.3ms ✅** | **−0.2~−2.2ms ❌** |

**结论**: 1m 参考距离本身足够（2.92ms = 46.7 样本缓冲）；**通用 codec 是凶手**，低延迟 codec 是硬前提；扬声器离误差麦越近越好。
- ✅ **达标**: 实测环路延迟（参考采样→anti 出扬声器）< **2.5ms**；🎯 理想 < 2.0ms
- ⚠️ 实测方法: 注入脉冲，测参考→误差传播总时间

### 11.4 相干性预算（需实测，算力救不了）

相干性回答"参考麦能否预测误差麦信号"，失相关来自湍流/多径/空间非均匀，**与算力无关**。

- 各种估计（同一 1m，结论差 2 倍）: 自由场=无上限 / 工程经验 c/d≈343Hz（偏乐观）/ 混响 sinc≈171Hz（偏悲观）—— **c/d=343Hz 非严格物理定律**
- **实证（Lam 2020, Sci Rep）**: 窗外干净参考 + 窗内误差区 + 24 扬声器，**300-1000Hz 中频实测 7-10dB** → 1m 级距离中频相干性够用；但多径混响强的室内单点参考麦 500Hz 有下降风险
- **结论**: "500Hz 必死"是过度简化。窗外干净参考 + 参考麦贴窗面（<50cm，相干上限 ~686Hz）→ 500Hz 安全；多径室内单点 → 上参考阵列补高频
- **Phase-1.5 阻塞项，必须现场实测，不能靠公式定论**
- ✅ **达标**: 500Hz 参考-误差**实测相干度 ≥ 0.8**，且纯音对消 ≥ 10dB

| # | 项 | 达标线 | 不达标对策 |
